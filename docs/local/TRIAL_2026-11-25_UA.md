# Harness²: обмежений модельний запуск — 25.11.2026

## Результат
На X99MG виконано локальний tool-calling probe та дві обмежені спроби однієї задачі JobBench data_entry_keyers/task1.
Локальна llama3.2:3b відповіла правильним tool_call check_local(value=7) за 11.17 с.
OpenCode успішно звернувся до моделі, але обидві спроби завершились base-failed, exit code 2, без файлів результату. Кожна мала два внутрішні attempts. Друга спроба завершилась за 39.57 с.
Повний Propose–Probe–Compose цикл і порівняння через judge не досягнуті: немає базового артефакту.
Платні/cloud моделі не викликались; :cloud записи в Ollama не вважались локальними моделями.

## Що змінилось
- docs/local/opencode-local.json: окремий localhost provider для llama3.2:3b.
- scripts/run_bounded_local.py: фіксований локальний профіль, одна задача, k=1, один worker, ліміт 1–1800 с.
- Linux subreaper прибирає detached/orphaned descendants після timeout або завершення головного процесу.
- Профіль ізолює XDG config/data/state і OpenCode home, відкидає успадковані конфігурації, вимикає зовнішні скіли, Claude config, default plugins, model metadata fetch та auto-update.
- tests/test_bounded_local.py: перевірки завершення detached child при timeout і orphan child після нормального виходу батька.

## Факти і припущення
У першій відповіді були назви скілів хоста; після вимкнення зовнішніх скілів модель все одно переказувала інструкції замість створення deliverable.
Ollama показала фактичний context_length=4096 для завантаженої моделі, хоча конфігурація OpenCode заявляла context=8192. Це потенційний фактор втрати контексту; причинність не доведена. Підвищення limit.context у JSON OpenCode саме по собі не є доказом зміни runtime context Ollama.
Поточний профіль llama3.2:3b не кваліфікований для цього JobBench workflow. Це не доводить несправність Harness² або всіх локальних моделей.

## Відтворення
На X99MG у /home/user/src/harness2:
```bash
.venv/bin/python scripts/run_bounded_local.py --seconds 300 --runs-dir runs/new-local-trial
```
Wrapper має додаткові обмеження, перевірені тестами; дві зафіксовані модельні спроби запускались до його створення з командним timeout.
Цей launcher очікує встановлений llama3.2:3b та Ollama на 127.0.0.1:11434; він не завантажує моделі.
Логи попередніх спроб: runs/local-llama-20261125/ і runs/local-llama-isolated-20261125/.
Tool probe: runs/local-preflight-20261125/model-probe.json.
Локальна конфігурація є керуванням поведінкою OpenCode, а не мережевим або OS sandbox.

## Готовність web ChatGPT
Наявний Desktop Commander дозволяє керувати хостом. Спеціальний Harness² MCP/plugin/skill для web ChatGPT цим кроком не створено.
Перед кваліфікацією моделі та повного циклу не можна позначати запуск як успішний.
Наступна перевірка: достатній фактичний runtime context і модель, здатна виконувати файлові інструменти на цьому завданні. Після цього — MCP start/status/results/cancel поверх bounded supervisor.
dell-T3500 цим кроком не оновлювався.
